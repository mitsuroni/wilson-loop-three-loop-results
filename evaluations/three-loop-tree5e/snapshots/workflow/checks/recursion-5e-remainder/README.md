## 检验发现的真实错误

旧`workflow/checks/tgv-t4-empty/assemble.py`先得到完整Q(-2…2)，再执行`series(evenQ,eps=0,3)`。Maple的3按最低Laurent幂计数：

| 代表/反射 | 平衡Q最低幂 | 实际保留到 | 正确需要到 | r001受影响的I位置 |
|---|---:|---:|---:|---|
| 13/35 | −2 | 0 | 2 | −1、0 |
| 14/34 | −1 | 1 | 2 | 0 |
| 15/33 | −1 | 1 | 2 | 0 |
| 40/43 | 0 | 2 | 2 | 无 |

最小实际控制：`series(exp(eps)/eps^2,eps=0,3)`只给ε⁻²+ε⁻¹+1/2+O(ε)。新预算作显式卷积，不再用这个调用猜绝对最高幂。原Q、P/S、C、积分域和全ε表示没有因此改写。

[预算诊断](budget-diagnosis.json)中的49个精确比较同时复现旧八图和及四代表的旧系数，并证明正确预算之和等于新递归八图和。最初“所有代表都截到0”的假设失败，保存在[失败记录](budget-hypothesis-failed.json)；第一次总和显式组装的对称重数错误也保存在[原失败记录](construction-normalization-failed.json)，随后按原规范改正。失败不是成功证据。

发布六个r002，修正八个单图位置；49个新表示精确回代原M/N/τ/E基底，没有新增超越生成元。新[当前索引](../../../benchmarks/tgv/5e-3g/current.json)供后续物理求和读取。旧组装脚本和旧报告作为历史保存；重新调用旧脚本仍会重现旧错误，复算应使用本目录的显式预算脚本。任何依赖旧r001的将来纯CFCA²组装必须切到current；已完成的三个物质颜色通道不含这些图，不受此更正影响。
