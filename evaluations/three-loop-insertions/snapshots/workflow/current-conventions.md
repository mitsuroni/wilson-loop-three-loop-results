# 当前计算的统一约定

本页是当前计算的简明接口规范；物理符号的唯一推导依据仍是
[共同作用量、路径序与 Fourier 规则](../benchmarks/theory/montopar/shared-sign-conventions.md)，
其约定标识为 `wilson-qcd-action-path-fourier/1.0`。本页不建立第二套物理规则。

## 从物理源确定符号

采用 Minkowski 度规 (+---)、D=4−2ε、Hermitian 生成元、
[tᵃ,tᵇ]=ifᵃᵇᶜtᶜ、Tr(tᵃtᵇ)=TF δᵃᵇ。场 Fourier 为 exp(−ipx)，
Wilson 输运方程为 U′=ig₀ A U，沿轮廓较晚的生成元在左。
动量 Wick 测度给 +i，内部坐标 Wick 测度给 −i。
完整 Π、Γ 插入算符包含其定义中的 i 与内部 Grassmann 闭圈符号，外部 Dyson 系数为 +1。
具体传播子、顶点、入射动量、导数方向和符号推导以唯一正文为准。

符号必须在原动量对象及颜色收缩时确定并进入 C/J。
后续组装不按图号、图族或已知答案决定校正号，不在运行中猜测旧版本并转换。
新原生输入缺少上述契约、混合契约或声明额外族级组装号时，当前入口拒绝读取。
真正的颜色系数、顶点相位、几何映射系数和耦合反项允许为负；它们不是符号补丁。

## C、J、I 与颜色

raw C/J 保留其声明的 cube／ordered 表示及对应映射、端点、传播子幂次、参数域、
积分次序、simplex 测度和 i0；不假定所有 raw 都是原有序参数表示。
raw 的 Euler 补偿次数为零；物理 prepared 先核验 C 各分量乘积及 Gamma 权重，
再加入一次 exp(−n γE ε)，保留 original_C、原 J 和原颜色。
现有 [原生准备 API](../preprocessing/native_physical.py) 不改变符号。

固定基底 a1 投影与物理符号规则分别处理。默认47个有序根仍保留其已接受的
投影、域和证明身份；完整物理颜色组装必须使用完整颜色信息与各族已经建立的
connected/web 连接。原生全颜色 prepared C/J 不能冒充已经完成该连接的 I。

现行物理 I 按各族定义包含其已提取的轨道/C4、反演 crossing 及一次 Euler 补偿。
恢复公共颜色、耦合和尺度时不再重复这些操作。归一化在原族中只证明到何处，
当前入口就记录到何处；没有统一的通用倍率可替代所有族的 C→I 推导。
四腿使用同一附着顺序的接触与交换联合 I，来源只消费一次。

## 记号与输出量

| 记号 | 唯一含义 |
| --- | --- |
| ε / 代码 eps | 维数调节参数，D=4−2ε |
| z、ρ / 代码 rho | 形状参数、ρ=log z；一般实计算域 z>0 |
| L | 物理平均尺度 (Ls+Lt)/2；Ls=L+ρ/2、Lt=L−ρ/2 |
| λ | αs_MSbar/π |
| T | TF nf；TF=1/2 |
| M_kj、N_kj | 原始无阶乘矩；N_kj=M_k,j+1−ρ M_kj |
| Sn | exp[nε(L+ρ/2)]+exp[nε(L−ρ/2)] |
| Un | 剥离公共外尺度、耦合及报告中指定公共颜色后的 connected 和 |
| Bn、CTn、Pn | Bn=Sn Un；耦合反项 CTn；Pn=Bn+CTn |
| logZ、Fn | Pn 的负 ε 阶部分、零阶部分；Fn 属于 log WR |

若 W=1+λW1+λ²W2+…，则 w1=W1、w2=W2−W1²/2。
已经采用 connected I 组装的 wn 不再作一次 W→log W 减除。
正 ε 阶系数为高圈反项输入，不是物理 ε⁰ 有限项。
三圈有限项至少需要一圈至 ε²、两圈至 ε¹；若提供两圈 P2 至 ε²，则需一圈至 ε³。

旧推导中的辅助r只在其局部定义中使用：矩变量r_M=z/(1+z)，某些腿积分的
r_leg=1/(1+z)，二者不能混同。当前总和使用共同z-HLOG或M/N函数族、ρ与L；
读取原积分的其他精确表示时仍须保留该表示的局部变量定义。
