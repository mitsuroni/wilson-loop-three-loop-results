# Fifteen three-loop insertion derivations

These current mathematical articles apply the fixed [documentation standard](../../../workflow/integral-documentation-standard.md) to eleven Pi1-plus-exchange, two serial-Pi1 and two single-Pi2 sources. Each own article keeps its exact original kernel and ordered bounds, then substitutes into an explicitly evaluated reduction and the complete external colour convolution.

Read [common normalization](common-normalization.md), [Pi1 plus exchange](pi1.md) and [serial Pi1 / single Pi2](chains-pi2.md). They derive the graph-specific bridges and state accepted physical roots and evaluated computational lemmas. The project's [current conventions](../../../workflow/current-conventions.md) remain the single physical interface.

The [runtime](runtime/README.md) is a byte-exact historical P5 packet copy. Its original scripts, mathematical snapshots and outputs retain their original scope. The supported Python entry recalculates source-normalized scalar/geometric and operator jets using adopted evaluated functions; it does not newly integrate the internal two-loop Pi2 tensor. Its old Markdown is provenance, whereas the current articles expose the mathematical steps.

Global dictionary loading and a particular graph's necessary subintegrals are distinguished in each data/index.json. Scalar/geometric I, complete transverse insertion, connected colour projection and full unprojected Wilson trace also have different meanings. The source operator is B1 for Pi1-plus-exchange, B1 squared for serial bubbles, and the full A+B/U expression for a single Pi2.
