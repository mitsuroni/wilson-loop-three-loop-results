## 复算

~~~powershell
D:/py/python.exe workflow/checks/permutation-masters/run_checks.py

~~~

run_checks.py每次新建运行目录，保存报告、代码/理论稿快照和具体复用输出的SHA-256；不覆盖旧运行。verify.py只读检查当前研究胶囊及投影矩阵。若要比较更高阶，需要新的实际积分与足够完整的低族候选，不能仅改动本报告的目标阶。

permutation_algebra.py实现与积分无关的有限排列代数；epsilon_filtration.py复用现有Hlog系数，做精确有理线性代数。完整不相容见证和转换在run下的JSON中，不以浮点拟合代替解析等价。
