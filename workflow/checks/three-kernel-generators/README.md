# 三核两个组合的全ε生成研究

正文：[三核行列式与混合组合](../../../benchmarks/2ne/theory/generation/three-kernel-generators.md)。本批是一次有界的全ε结构探索，没有宣称求出两个目标的有限标准函数闭式。

## 本轮得到的解析连接

1. 任意矩形上的单核原函数显式求为四个已有3F2原函数的组合，保留全部边界。
2. 同序三核降为单核乘左下/右上矩形原函数的二维积分。
3. 行列式等于两个已知低核乘积减去四倍边界加权单核；混合组合另需上述矩形耦合。
4. 行列式的加权矩经两次带边界分部积分，得到一个单重对角矩级数。每个系数由已求值的Beta/2F1端点矩平方产生；一般z需要从辅助参数的小圆内沿指定实路径延拓。
5. 裸核在整数ε处的秩退化给出独立控制：行列式在ε为1时至少二重零、在2时为零；混合组合在2时一般不为零。

## 实际通过的检查

- [algebra.json](algebra.json)：两个独立对称多项式核的原六维有序积分与全部二维恒等式；矩形四角及混合导数；整数ε秩控制。
- [numeric.json](numeric.json)：3个35位原矩形积分，12个原六维Sobol对照。每组使用3个独立扰动、各2的18次方个点；两个不同网格的二维求积同时记录。
- [moment-series.json](moment-series.json)：9个50位边界矩、3个辅助参数级数与二维积分对照，以及物理z为1时的加权矩。
- [coefficients.json](coefficients.json)：从既有结果精确组装两个新坐标的零阶、一阶，核验组合关系；这些是复用与坐标变换，不是本轮新积分。
- [旧权重7证据](../weight-seven/README.md)经只读验证；没有修改其指针、报告或结果。
