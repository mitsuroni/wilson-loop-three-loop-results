# Current convention and consumer migration

This public entry preserves the completed WILSON-6.3 scientific migration. Use
the [English current guide](../../../docs/current/README.md),
[single physical convention](../../current-conventions.md),
[current catalogue](../../../benchmarks/current/catalog.json) and
[actual publication replay](../../../validation/current-2026-11-02/README.md).

The active low, matter, AA and combination programs in this directory are the
exact code bound by workflow/current-calculation.json. They directly consume
current native integral data without family sign conversion. Historical totals
are checked after construction as holdouts or exact compact representations.
Source/helper scripts in other research directories retain their original bytes
and are reused only for the documented mathematics; their old output writers
are not normal production commands.

The three-loop current selector points to all four adopted color channels.
Original integrals, dictionaries and accepted I2344/I1234 derivations retain
their research evidence scope; no old proof status is transferred. For provenance
use the current reader's explicit --provenance option. formal=not_run.
