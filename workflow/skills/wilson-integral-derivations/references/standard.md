# 逐积分连续推导与计算资料标准

版本1.0，2026-11-03；用户确定采用，先在一圈2个、两圈12个积分试行。本标准规定整理和审核，不授予历史结果新的数学证明身份。

## 对象和阅读结构

目标：读者从本图初始积分，沿正文及明确数学附录，读到全部指定Laurent系数。

```text
integrals/
  README.md
  one-loop/<id>/
  two-loop/<id>/
  three-loop/<ordinary-id>/
  three-loop/four-leg/<attachment>/
  families/<family>/                 共享数学、程序和母函数数据
```

普通源保留自身入口；对应条目给完整映射后采用代表结果；四腿先列来源/权重，再推导联合I；零项给具体零值论证。源数、联合对象数、方法数和IBP主积分数分别计。

| 文件 | 必需职责 |
|---|---|
| README.md | 对象、几何/腿分布、目标阶数、阅读/运行入口和具体缺口 |
| derivation.md | 初始积分到完整系数的连续数学正文 |
| reproduce.md | 环境、每阶段命令/输入输出、程序分工、续跑与复用范围 |
| validation.md | 实际检查、独立性/共享输入、精度与未覆盖范围 |
| input.json | 源/字段/版本、域序和归一化绑定，复用既有schema |
| result.json | 完整阶数、零项、余项、精确HLOG/GPL/函数族，保留采用身份 |
| code/ | 本图特有程序或可执行共享入口，注明实际作用 |
| data/ | 必需解析中间结果或稳定索引，不能用最终表冒充原语 |
| checks/ | 实际核验输出或稳定索引，求积与验证分开 |

复杂对象按需增加subintegrals.md、appendices/*.md；历史链长才增加provenance.md。不造无用途文件。共享物理规范只引用项目唯一约定；导航不加English标签。原生大输出可共享，索引须说明对象、用途、路径与版本。

## 连续数学正文

这些是内容要求，不是固定章节模板。简单积分可合并叙述；复杂积分可延长附录。

1. **起点**：写实际动量/参数积分、全部因子、变量、原有序域、D、i0、初始收敛区和目标阶数。Pi/Gamma有效算符或C/J作为已知根时明确范围及上游连接；不能只给图号或JSON。
2. **参数核**：定义本图分子/分母；换元给Jacobian和边界。长分子可用定义完整的张量/导数记号，不能仅说保存在文件。
3. **归一化**：解释C/J/I与颜色、尺度、C4、crossing、Euler各在哪里进入；从当前源确定符号，不在主线追加历史补号。
4. **实际约化**：展示积分、IBP或微分系统怎样得到本图分解；保留接触面、recoil、共同调节与操作条件。不能从原核跳到已求母式。
5. **子积分**：给每个必要对象的积分定义、域、实际所需epsilon阶和解法；终点是完整解析表达或条件明确的已求函数，不是另起名字的未知余项。
6. **CAS**：给实际核、变量次序、正则化、关键中间式/原函数、端点常数及核验。允许CAS做机械运算，但“运行成功”不构成数学步骤。
7. **组装与展开**：写子积分和prefactor怎样得到目标系数；pole乘正阶不可漏。至少展示最困难/最高要求阶的实际组装，其余可用明确有限求和或递推统摄。给全部指定零项和余项。
8. **函数表示**：定义HLOG/GPL、字母/周期、函数族及换基常数/分支。大词表可不印全文，但须有可重建的精确式/有限索引规则和可读函数形式，不能只有文件指针。
9. **采用与范围**：有效采用已求结果时给精确陈述、定义、域、阶数、归一化和本图代入，定位其实际推导/求积。epsilon局部延拓、复z、负一边界分别声明。

通用Euler/Beta等引理可引用；本图的具体代入、非平凡边界以及初始积分到求值母式的桥梁必须出现在主文/明确数学附录。来源、代码、预算JSON和结果表不能填补中间数学步骤。

## 程序与数据

按实际计算选语言，不强制三语齐备：Wolfram/FeynCalc用于实际张量/颜色/参数化；Maple/HyperInt或其他CAS求积和端点；Python/Wolfram/Maple作精确展开、换基、组装。验证程序另列，不改名为求积程序。

正文步骤、调用入口、中间输出三者对应。批处理.wl/.wls/.mpl/.py不依赖手动内核状态；Notebook可保留探索用途。历史writer的旧绝对输出不直接运行，只加必要薄适配，不改冻结原件。

生成不读取最终参考表。已求原语可采用，但须标明它是子积分、已积分J还是归一化I；后置比较不能称为新原积分求解。中间结果声明变量、域/分支、阶数、归一化，保留原格式；运行元数据不冒充数学证明。

## 五项分别验收

| 维度 | 达标依据 | 不充分依据 |
|---|---|---|
| 正文 | 实际数学链连续，非平凡等号/端点有解释 | 有MD、公式多、来源多 |
| 实现 | 程序完成所声明步骤，输入输出与正文一致 | 有三种语言文件或旧表reader |
| 复现 | 新目录实际执行并得到匹配结果 | 只保存日志、哈希或导出证书 |
| 数学验证 | 检查连接原对象，共享输入/独立性披露 | 只旧表、只数值、只RG |
| 发布 | 导航、资料、依赖符合实际公开范围 | 本地完成或任务Done |

逐积分审核指出具体式/段落和程序/原资料证据，并回答：这一式怎样得到、操作条件是什么、必要子积分在哪求完、系数怎样组装、哪里是已知输入。

状态可为“正文可连续阅读”“明确采用已求引理，链已接通”“仍有具体正文/实现缺口”。缺口写对象、缺失步骤和影响范围；不得为了通过而降低目标或把缺失推导称作有效复用。旧数学采用保持，文档缺口不是反证。

机械链接/字节/语法检查单列，不能自动授予正文合格。全包状态不能掩盖单篇失败；格式重组和数学连续性分别报告。
