# Montopar: momentum definitions to parameter integrals

This is the published source snapshot of Montopar 0.1.0. It reads the project's
`orbit_definitions.json` and constructs explicit parameter-space prefactors and
integrals, with their numerator, measure, ordered domain, denominator powers,
color/phase conventions and optional contour-IBP representations. It does not
evaluate I or provide its Laurent coefficients.

## Installation and a CAS-free example

With Python 3.12 or newer, from the public repository root:

```text
python -m pip install -e packages/qgraf-pipeline -e packages/montopar
qgraf-pipeline 2 --output-dir generated/2loop --no-pdf
montopar --source generated/2loop/orbit_definitions.json --type 2e-Pi1 --out-dir generated/parameters --package-initial
```

The equivalent module entry point is `python -m montopar.cli` with the same
arguments. **The output option is `--out-dir`.** Give it explicitly, because
the original default searches for an enclosing Git repository. The package
does not overwrite the historical scientific snapshots under `data/`.

The example uses the implemented native one-loop self-energy insertion and
needs no CAS runtime. The Python core has no non-standard-library imports.
This does not make every dispatch CAS-free: generic pure/TGV/mixed color
evaluation calls an external `wolframscript` with FeynCalc on its search path.
That external backend is not bundled. FGV/double-TGV and implemented effective
insertion families have their documented native color/operator paths.

## Input and mathematical contract

Current native inputs must declare the physical convention
`wilson-qcd-action-path-fourier/1.0`; undeclared legacy inputs are rejected.
The convention fixes Wilson path ordering, color trace order, Fourier phases,
Wick signs and internal-loop signs. Raw native C/J contains neither the
downstream Euler compensation nor the a1 color projection. Cyclic-orbit
normalization is family-specific: inspect each payload's C/components/symmetry
and its representative or rotated-partner definition. Stored multiplicity
metadata and an already applied multiplicity are distinct; the downstream
assembler must count each factor exactly once.

The package exports family-specific representations for pure exchange,
three/four-gluon vertices, mixed/double-TGV and supported self-energy/central
vertex insertions. Check the result's own schema and dispatch: the distribution
version `0.1.0` is not a universal schema version. The original ordered s-domain
and a transformed cube are alternative representations, not additive terms.

If a contour-IBP output has multiple terms, retain boundary/contact/recoil
terms and their own `combined_C`. A scalar field called `J.integrand` is an
integrand, not an evaluated J. An exported identity or local certificate is
not a proof of a complete Laurent coefficient.

Useful options include `--orbit-id`, `--type`, `--package-initial`,
`--tgv-ibp` (also `--gamma1-ibp`), `--double-tgv-forms` and
`--double-tgv-operator`. See `python -m montopar.cli --help` and the preserved
theory docs for each option's scope. The raw integral remains available beside
optional reduced forms. The ordered integration prescription is retained.

## Source snapshot and tests

`PUBLICATION-SOURCE.json` records original/published hashes and exclusions.
Source/tests and included original docs preserve their bytes. Some original
theory pages cite historical workspace paths; those citations describe the old
research environment, not portable dependencies of the installation above.
The [original README](README.original.md) contains dated development history;
its historical unsupported/rotated statements are not the current interface.

The current dirty source snapshot and frozen historical C/J products have
separate manifests. Do not infer that a historical product was generated by
this snapshot merely from a shared package version or parent commit.

Tests use pytest, SymPy and NumPy; the optional slow color integration test
needs the external Wolfram/FeynCalc backend. From this package directory:

```text
python -m pip install -r requirements-test.txt
python -m pytest -q tests -m "not slow" -p no:cacheprovider
```

These are software regression checks. They do not establish that all exported
integrals have been analytically evaluated or formally proved. No external CAS
installation, cached output, personal configuration or binary is bundled here.
