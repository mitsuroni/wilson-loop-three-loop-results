# TGV腿自能的完整轮廓IBP

2026-10-01。本文补齐直接参数化理论之后的轮廓分部积分。原始对象、符号、全色系数及两项直接核采用[parametric-theory.md](tgv-pi1.md)。本次IBP不改变raw C、颜色、Euler补偿或I定义。对应生产模块为 `tgv_pi1.py` 与 `tgv_pi1_ibp.py`。

要提取轮廓边界，关键是完整自能张量中含外腿纵向动量的部分本来就是标记路径的全导数；不能把整个投影当作传播子改幂。以下先在独立坐标、共同有限调节及α内部成立，再限制到有序轮廓域。

## 1. 将中心张量拆成标量项和二阶坐标导数

用ξ_i=X_i/√A₀、ū_i=u_i/√A₀表示无量纲坐标和切向量，A₀=−2v₁₄>0固定。记α₁+α₂+α₃=1，ℛ_i=ξ_i−Σα_jξ_j，G_ij=ū_i·ū_j，T_ij=ū_i·ℛ_j，W_ij=ℛ_i·ℛ_j。微分时ū与A₀固定；D=4−2ε。

设ν=1−3ε、m=ν+1，Q=−Σ_{i<j}α_iα_j(ξ_i−ξ_j)²+iη。共同权重w_r=α_r^{-2ε}∏_{j≠r}α_j^{-ε}与所有路径参数无关。直接理论的中心张量方括号为

$$B_{\mu\nu}^{[r]}=(1+2\epsilon+\alpha_r)g_{\mu\nu}Q^{-\nu}
-2\nu\alpha_r\mathcal R_{r\mu}\mathcal R_{r\nu}Q^{-\nu-1}.$$

由∂_{iμ}Q=−2α_iℛ_{iμ}可得

$$\partial_{r\mu}\partial_{r\nu}Q^{1-\nu}
=2(\nu-1)\alpha_r(1-\alpha_r)g_{\mu\nu}Q^{-\nu}
+4(\nu-1)\nu\alpha_r^2\mathcal R_{r\mu}\mathcal R_{r\nu}Q^{-\nu-1}.$$

因此同一个完整张量精确写成

$$\boxed{B_{\mu\nu}^{[r]}=2(1+\epsilon)g_{\mu\nu}Q^{-\nu}
-\frac{\partial_{r\mu}\partial_{r\nu}Q^{1-\nu}}{2(\nu-1)\alpha_r}.}$$

此中间式的1/(ν−1)由二阶微分抵消；最终通量不需要除以α_r或ν−1。不能在相消之前把ε置零。有限η不依赖ξ，所以微分公式及等式也在有限共同调节下成立。

## 2. 完整纵向部分成为标记路径导数

令(r,s,t)为标记腿及其循环后两腿。直接核等于三胶子坐标算子作用于B后除以2ν。二阶导数项中的ū_r·∂_r正是∂_{s_r}，余下第二阶算子是

$$\mathcal W_r=-(\bar u_s\cdot\partial_r)(\bar u_t\cdot\partial_s)
+(\bar u_t\cdot\partial_r)(\bar u_s\cdot\partial_t)
+G_{st}\,\partial_r\cdot(\partial_s-\partial_t).$$

这个式子由原树顶点将第r条切向量换成对应动量后得到。常系数坐标导数可交换，故纵向部分为∂_{s_r}b_r^{long}，其中

$$b_r^{long}=-\frac{\mathcal W_r Q^{1-\nu}}{4\nu(\nu-1)\alpha_r}.$$

对s≠r、t≠r展开两次导数，并保留度规迹D，得到不含未执行导数的通量：

$$\boxed{b_r^{long}=\frac{D-1}{2\nu}G_{st}(\alpha_s-\alpha_t)Q^{-\nu}-H_rQ^{-m},}$$

$$H_r=-\alpha_sT_{sr}T_{ts}+\alpha_tT_{tr}T_{st}
+G_{st}(\alpha_sW_{rs}-\alpha_tW_{rt}).$$

H_r直接按上式生成，不通过F_r/T_rr做除法；即使T_rr=0也定义良好。直接理论的F_r=T_rr H_r。

## 3. 标量树顶点部分的路径导数与余项

度规部分对应2(1+ε)L/Q^m。若两腿同边，树顶点的完整一次算子已经沿路径，可取以下系数c_i：

| 同边条件 | (c₁,c₂,c₃) | 标量余项 |
|---|---|---|
| e₂=e₃ | (0,−G₁₂,G₁₃) | 0 |
| e₁=e₂ | (−G₁₃,G₂₃,0) | 0 |
| e₁=e₃ | (G₁₂,0,−G₂₃) | 0 |

当三条边互异，对平移不变的中心核有Σ_i∂_iQ=0。在每个循环项中使用∂_i−∂_j=2∂_i+∂_k，选择

$$c=(G_{23},G_{31},G_{12}),$$

并保留显式recoil分子

$$\mathcal R_{num}=4(1+\epsilon)\sum_{(i,j,k)\,cyclic}G_{ij}\alpha_iT_{ki}.$$

这是一种确定且可核验的分解，不声称它使主积分数最小。三边图不得预设余项为零。

## 4. 最终可输出的全导数和余项

定义所有三条路径的通量

$$b_i=\frac{b_{0i}}{\nu}Q^{-\nu}+b_{1i}Q^{-m},$$

$$b_{0i}=(1+\epsilon)c_i+
\delta_{ir}\frac{D-1}{2}G_{st}(\alpha_s-\alpha_t),\qquad
b_{1i}=-\delta_{ir}H_r.$$

令直接两项分子K₁=(1+2ε+α_r)L−α_rE_r、K₂=−2mα_rF_r，则

$$\boxed{\frac{K_1}{Q^m}+\frac{K_2}{Q^{m+1}}
=\sum_i\partial_{s_i}b_i+\frac{\mathcal R_{num}}{Q^m}.}$$

同边重复附着时R_num=0。生产模块对每张图分别核对以下多项式等式，不以数值相近替代：

$$K_1=\sum_i(\partial_{s_i}b_{1i}-b_{0i}\partial_{s_i}q_0)+\mathcal R_{num},$$
$$K_2=-m\sum_i b_{1i}\partial_{s_i}q_0.$$

其中b₀与路径无关，q₀不含iη。有限调节下的两个分母幂独立重构，所以没有在通分过程中丢弃iη分子。

## 5. 在原有序域上的端点与接触面

对任意同边链0≤s₁≤…≤s_n≤1，使用继承参数测度的通量为：下端−b₁，上端b_n，接触面s_j=s_{j+1}为b_j−b_{j+1}。因此

$$J_{raw}=\int d\mu_\alpha w_r
\left[\sum_f\int_{D_f}dt\,\sum_i n_{fi}(b_i\circ\phi_f)
+\int_{D_\rho}d^3s\,\frac{\mathcal R_{num}}{Q^m}\right].$$

每个接触面只输出一次，两个相邻槽位的法向贡献先合并。限制到面之前，父空间微分已经完成；本分解只有一层轮廓IBP，不需要双TGV第二层的额外法向投影。面约束、剩余排序链、原外到内顺序去掉被消变量、α测度及共同C均逐项保存。不把接触面剩余域改成独立立方体。

实现中消去α₃=1−α₁−α₂，α₁外层[0,1]、α₂内层[0,1−α₁]，Jacobian=1；原三个Wilson变量的嵌套顺序不变。非零边界通量一般留下两个Wilson参数加两个α参数；三边图另有原五维recoil。输出行数如下，不作为独立主积分数：

| 源图 | 边界行 | recoil行 |
|---|---:|---:|
| 01、02、05、06、07、08 | 3 | 0 |
| 03、04 | 4 | 0 |
| 09 | 5 | 0 |
| 10、11、12 | 6 | 1 |

若某面几何q₀恒等零，仍须保留共同有限iη并在组合后取边界值；不能把该面自行解释为普通无调节积分并删除。

## 6. 验收范围与尚未完成的工作

在有限η>0及α内部截断下，本等式是光滑紧致轮廓域的普通IBP。随后须沿原直接核的共同解析边界值和亚纯延拓解释，所有项先组合；没有证明所有拆分项在ε=0或所有复运动学区域分别可积。ν=0等人工分母的特殊值也应在完整组合中取延拓极限。

本次实际验证：12图在两个分母幂上精确回代；raw几何与既有独立夹具相符；相邻两边、对边及三边代表的四次C4旋转同时核对标记腿、α重排、原s域及q₀/L/E/F的尺度次数；CLI及打包、源错误和输出篡改控制通过。详细结果见[生产验收记录](tgv-pi1.md)。
