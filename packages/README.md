# Upstream source packages

The two self-authored packages form the first stages of the calculation:

1. [qgraf-pipeline](qgraf-pipeline/README.md): generate and classify Wilson-loop diagram orbits using the project's combinatorial implementation; optional interfaces also support existing QGRAF output.
2. [Montopar](montopar/README.md): turn supported orbit definitions into parameter integrals C/J and optional contour-IBP expressions.

Use each package's English README for exact commands, dependencies and tests. Source versions and any publication-only portability changes are bound by the package manifests. Their original producer code is preserved where stated; a current-source package is not automatically the producer of every frozen historical data file.

The [input catalogue](../data/README.md) supplies the frozen mathematical inputs used by the calculation. Packages are published here as source, not as an assertion that every original integral was independently proved or that all downstream Laurent coefficients can be regenerated in one command.
