# ff: $`C_F (T_F n_f)^2`$

The external factor is `lambda^3 * CF*(TF*nf)^2`. This page gives every coefficient from epsilon^-6 through epsilon^0 in the [common moment convention](conventions.md). It contains 2 orbit contributions.

```math

\begin{aligned}& - \frac{L^{4}}{54} - \frac{10 L^{3}}{81} + \frac{L^{2} \rho^{2}}{36} - \frac{25 L^{2}}{81} + \frac{\pi^{2} L^{2}}{18} - \frac{L M_{1,1}}{9} + \frac{5 L \rho^{2}}{54}\\ & {} - \frac{4 L \zeta\left(3\right)}{9} - \frac{232 L}{729} + \frac{5 \pi^{2} L}{27} - \frac{5 M_{1,1}}{27} - \frac{M_{2,1}}{36} + \frac{\rho^{4}}{864}\\ & {} + \frac{\pi^{2} \rho^{2}}{216} + \frac{25 \rho^{2}}{324} - \frac{110 \zeta\left(3\right)}{243} - \frac{7 \pi^{4}}{19440} + \frac{32}{6561} + \frac{38 \pi^{2}}{243}\end{aligned}

```

```math

\begin{aligned}& - \frac{5 M_{1,1}}{27} - \frac{M_{2,1}}{36} + \frac{\rho^{4}}{864} + \frac{\pi^{2} \rho^{2}}{216} + \frac{25 \rho^{2}}{324} - \frac{110 \zeta\left(3\right)}{243}\\ & {} - \frac{7 \pi^{4}}{19440} + \frac{32}{6561} + \frac{38 \pi^{2}}{243}\end{aligned}

```

```math

```

