# Integral input catalogue

This index follows the frozen **2026-11-02** upstream data catalogue: 163 source orbits across 13 families, with original raw C/J available for every entry. The one-, two- and three-loop catalogues contain 2, 12 and 149 orbits, respectively.

Separate existing prepared payloads are available for 126 orbits, in 144 representation/version occurrences. The prepared count below counts available alternatives for one orbit; it is not a multiplicity or a number of independent calculations. A zero count means no separate prepared payload was included in this batch, while the raw input remains available.

A source orbit is a canonical representative, possibly containing an effective self-energy or vertex operator. The count is not a new microscopic QCD graph completeness claim. Four-leg source rows remain separate here and also map to their joint objects; they must not be counted twice in a color sum.

The raw C/J link opens the complete byte-preserved native family package. The per-integral input JSON identifies its exact orbit/field pointers and hashes; the English page explains the domain, normalization and available alternatives. These are input definitions. This index exports no Laurent coefficient or new integral derivation, and it does not reinterpret historical status labels.
