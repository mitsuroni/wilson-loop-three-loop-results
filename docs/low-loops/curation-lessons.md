# What the one/two-loop pilot teaches us about publishing three loops

The difficult part was preserving the meaning of each object as it moves to the
next stage. All fourteen low-loop orbits already had research results, yet a
collection of their last JSON files would not explain which source, sign, color
projection and scale convention a colleague must use. This pilot now carries
that chain through finite color results and external checks.

## What can be batched and what still needs human reasoning

The directory template, checksums, source copying, links, exact Laurent parsing,
prefactor convolution, color assembly and scale/CT expansion can be automated.
One family program should generate several per-orbit results; fourteen copies of
one program would make future corrections harder to review.

The integral definition, domain transformations, boundary prescriptions, operator
sign and connection from an ordinary graph to a connected contribution need explicit
mathematical reasoning. Reuse is legitimate when its exact statement and source
version match; neither a new filename nor a passing replay creates that connection.
The difficult TGV04 part illustrates this: its historical HyperInt integration and
complete dictionary are genuinely reused, while the new series/representation
conversion and original/reduced-kernel numerical controls are separately recorded.

## How to proceed at three loops

Start from the existing 149-source catalogue and current accepted result selections.
Build a source-to-result ledger before copying the downstream outputs: independent
orbits, reflection-related orbits, and the nine four-leg joint objects need distinct
identities. Then curate one complete family at a time using the low-loop packet
structure: original definition and normalization, continuous English derivation,
actual integration or explicitly reused route, exact Laurent/HLOG/MN data, source
and boundary controls, and a fresh-directory reproducer.

Once a family is frozen, add its contributions to the complete four-color ledger.
Keep each lower-loop S1/S2 inside its counterterm and restore S3 only for the genuine
three-loop term. Reproduce all Laurent coefficients, RG and finite results from
those declared individual/joint inputs. The full four-color research milestone
already exists; this is the publication and review plan, not a new claim that its
integrals remain mathematically unsolved.

For the difficult four-leg finite answers, record the original joint source,
subtractions, common boundary/branch conventions, HLOG result and function-family
conversion together. A reader should be able to see where an integration was
performed and which earlier statement was reused. The low-loop pilot supplies
the portable structure; it does not replace the stronger finite-shape evidence
required for those three-loop objects.
