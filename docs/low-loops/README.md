# Low-loop publication pilot

The [complete one/two-loop packet](../../results/2026-11-02-low-loops/README.md)
shows how to read the repository along the scientific data flow. It includes all
two one-loop and twelve two-loop orbit contributions, rather than a representative
subset. Start with its [continuous derivation](../../results/2026-11-02-low-loops/derivation.md),
then inspect one integral and reproduce the color sum.

The [one-loop articles](../../integrals/one-loop/README.md) make the simplest
original integration and normalization visible. The [two-loop articles](../../integrals/two-loop/README.md)
show how shared mother functions and explicit HLOG reuse scale across a family.
The [lessons](curation-lessons.md) describe the actual obstacles encountered and
the resulting plan for three loops.
